Sobre

Quem está por trás do código

Sou desenvolvedor e gosto de resolver problemas com clareza: menos camadas, menos ruído, mais resultado. Meu foco é a experiência de quem usa — carregamento rápido, navegação previsível e acessibilidade desde o início, não como um passo final.

Trabalho principalmente com a plataforma web, sem depender de frameworks quando o problema não pede. Este site, por exemplo, é HTML, CSS e JavaScript puros, publicados automaticamente no GitHub Pages.
