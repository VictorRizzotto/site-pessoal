01 Sobre

Quem está por trás do código

Curso Ciência da Computação na Atitus e uso o tempo fora da aula para construir produtos de verdade. O mais completo deles é o TapHub, uma plataforma SaaS com NFC que ajuda negócios locais a compartilhar sua presença digital — do banco de dados ao deploy.

No TapHub uso React, TypeScript, Tailwind CSS e Supabase. Quando o projeto pede algo mais leve, vou de HTML, CSS e JavaScript puros, como neste site. Versiono com Git e publico no GitHub, na Vercel e no GitHub Pages.
